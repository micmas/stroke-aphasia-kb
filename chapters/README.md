# Stroke KB chapters

Aphasia and Dysphagia are sibling evidence domains in one knowledge base.
Bibliographic identities, source PDFs, anatomical entities and processing tools
are shared. Eligibility, findings, extraction configuration, review and coverage
are chapter-specific. Membership is not eligibility or approval.

| Chapter | Permanent public address | Current state |
|---|---|---|
| Aphasia | https://aphasia-kb.app/ | Existing evidence and screening workflow |
| Dysphagia | https://dysphagia-kb.app/ | Protocol preparation; no approved chapter corpus |
| Stroke KB | https://stroke-kb.app/ | Planned shared homepage |

These are intended permanent addresses, not a claim that the new domains are
configured or deployed. See [migration](../docs/CHAPTER_MIGRATION.md).

The existing collection folders remain in place. A finding's `chapters` list
assigns it to one or both chapters, overriding its entry's default. Do not copy
papers or findings into duplicate directory trees. Existing identifiers, source
passages, review stamps and approval decisions must survive migration unchanged.
